# PM AI 模板库 Demo

一个基于 `Next.js + React + TypeScript + Tailwind CSS + shadcn/ui 风格组件` 的高保真 SaaS 展示站 Demo。

## 页面

- 首页
- 模板库页
- 模板详情页
- AI 生成器页（Mock）
- 价格页

## 本地启动

```bash
npm install
npm run dev
```

如果你本机使用的是 `pnpm`，也可以：

```bash
pnpm install
pnpm dev
```

默认访问地址：

```bash
http://localhost:3000
```
